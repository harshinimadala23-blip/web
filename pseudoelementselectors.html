Web technology includes the tools and systems that let us use and build websites on the internet. Core Parts of Web Technology • HTML builds the basic structure and text of a web page. • CSS adds colors, fonts, and designs to make the page look nice. • JavaScript makes web pages active and interactive with moving parts and pop-ups. • Web Server stores website files and sends them to your device when you visit a site.
